deployment, authority or model access. It is separate from the consumed
whole-three operation. Existing once16/native27 source, historical receipts,
`.spent`, OneRequest and the accepted contest83 distribution are unchanged.

`OneBackend()` defaults to refusal before a client, credential, filesystem
capture or remote operation is obtained. `native_binding()` is None. Even a
replaced loader returning JSON, a dataclass, Boolean or callback cannot release
this constructor: no reviewed native issuer/client wiring exists. Source pins
and Python private attributes are not an authority or sandbox.

The explicit `synthetic_backend` route is trusted inert test code. Its fresh
operation `TRACEHARBOR_FRESH_ONE_BACKEND91_V1` uses only the dedicated namespace
`refs/tags/traceharbor-one91-consumed/`. The key binds operation, repository ID
and nonce. The exact immutable record binds invocation, source parent, project,

classification explicitly remains SYNTHETIC and native_grant remains None.

The adapter validates its plan before any client operation, consumes its local
attempt before invoking the client, creates content-addressed blob/tree/commit
objects, then issues exactly one create-only ref request. Only that last Git
primitive is the durable atomic ABSENT-to-ATTEMPTING_CONSUMED transition.
Orphan objects from an earlier failure are not proof that a claim was created.
There is no ref update, delete, reset, preflight adoption, retry or refund.

After exact201 creation it reads repository identity, exact ref, commit with
sole source parent, exact one-member tree and entire blob bytes. It compares
the complete canonical record and Git blob/tree identifiers. A successful
receipt is cached only inside the same invocation; a new instance does not
adopt it. A changed, partial, foreign, late, conflicting or ambiguous response
stops the operation. UNKNOWN is sticky, with no second create or inference.

PrivateOriginals first retains actual returned/exception objects, then writes
bounded private diagnostic capsules (0600, explicit 0700 directory). A separate
O_EXCL marker supplements same-directory restart protection. These are local
test evidence, not a cloud lease, independent backup, cross-runner exclusion,
native private escrow or an unforgeable issuer. Diagnostics are private and
must not be supplied real credentials through the synthetic route.

socket/DNS/subprocess denial and fake Git only. It does not replay once16,
native27 or the already consumed 88/89 qualifications. It makes no actual Git
claim, model request, workflow dispatch or credential lookup.
