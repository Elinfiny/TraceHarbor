# One complete evidence-review journey

Use the existing Python 3.12+ standard-library setup in START_HERE.md. No dependency,
key, account or network call is needed for reference mode. This guide does not start
the app or override a browser restriction. All input and footage must be synthetic.

1. Open Full. Confirm the visible NO AI CALLS label, reference assessment and source
   counts. Inspect the incident timeline and timing uncertainty. Follow one support
   citation: the source panel opens, receives focus and shows the exact event/digest.
2. Open Missing. Locate the uncertain assessment and the requested missing decisive
   sample. Compare with Full without claiming the retained quote alone proves cause.
3. Open Conflicting. Inspect both support and contrary citations and source provenance.
   Hostile text is data displayed with textContent, never an instruction to execute.
4. Read the remediation proposal's preconditions, risk, rollback and verification.
   There is no execution action. Do not add one for the contest.
5. Export the current dossier, then choose Verify imported dossier and import it.
   Inspect recomputed structure, source hashes, quote consistency and dossier digest.
   Imported origin/provider invocation remains unauthenticated by an unkeyed hash.
6. For the demo, keep the original export unchanged. Make one separate synthetic
   copy and change a cited quote without updating hashes. Import the changed copy;
   the verifier must reject it. Preserve the real error/receipt and do not splice
   a mocked rejection into footage. This action is prepared, not performed in159.
7. Inspect an unsupported synthetic case: unknown/abstention, no invented diagnosis.
   Exercise 256 KiB rejection and a malformed JSON input only in later admitted QA.

Proposed new acceptance observations (not a replay of consumed historical suites):
one real keyboard journey; one 390px and one 1440px viewport; one export/import plus
changed-copy refusal; authentic live record after separate admission. Preserve the
first failed observation, source pin and exact error. Do not rerun an UNKNOWN effect.

The code paths are present in canonical web/app.js, service.verify_dossier and
verifier.verify_analysis. Source inspection establishes implementation, not visual
QA or a completed UI demonstration. Current hosted-demo availability is unverified.
